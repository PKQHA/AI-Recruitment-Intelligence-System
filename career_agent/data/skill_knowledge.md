# AI 招聘技能知识库

## Python
Python 是 AI 工程岗位最常见的基础技能。学习重点包括基础语法、面向对象、异常处理、文件读写、虚拟环境、依赖管理和常用标准库。实践建议是完成一个可运行的命令行工具，并把输入、处理流程、输出结果写清楚。

## OpenAI SDK
OpenAI SDK 用于调用聊天模型、向量模型和工具能力。学习重点包括客户端初始化、环境变量管理、模型参数、错误处理、JSON 输出约束和 Embeddings 调用。项目中可以体现为模型调用封装、Prompt 模板管理和统一异常处理。

## LangGraph
LangGraph 用于构建可控的 Agent 工作流。学习重点包括 StateGraph、State、Node、Edge、START、END、compile 和 invoke。实践建议是把复杂任务拆成多个节点，例如技能提取、匹配、检索、建议生成和报告组装。

## Tool 调用机制
Tool 调用机制用于把可复用能力封装成标准动作。学习重点包括工具名称、参数、返回值、注册表和调用链路。实践建议是把技能匹配、知识检索、学习路线生成分别封装为 Tool，让工作流节点只负责调度。

## RAG
RAG 是检索增强生成，用于让模型回答时参考外部知识库。学习重点包括文档加载、文本切分、向量化、相似度检索、上下文拼接和回答生成。实践建议是构建一个技能知识库，用缺失技能作为查询，检索学习资料和项目建议。

## FAISS
FAISS 是高性能向量检索库，适合本地构建轻量向量知识库。学习重点包括向量索引、相似度检索、索引持久化和重新构建。实践建议是把技能知识库文本转成向量，保存为本地索引，并在分析时按缺失技能召回相关片段。

## Prompt Engineering
Prompt Engineering 用于控制模型输出质量。学习重点包括角色设定、任务描述、输出格式、约束条件、示例和错误兜底。简历中可以描述为“设计结构化 Prompt，约束模型输出 JSON，提升结果稳定性”。

## NLP 信息抽取
NLP 信息抽取关注从非结构化文本中提取结构化字段。学习重点包括关键词抽取、实体识别、文本清洗、同义词归一化和结果评估。实践建议是对 JD 和简历抽取技能，并比较抽取结果的一致性。

## FastAPI
FastAPI 常用于把 AI 能力封装成 Web API。学习重点包括路由、请求体、响应模型、异常处理和接口文档。实践建议是把当前终端 Agent 扩展为 `/analyze` 接口，输入 JD 和简历，返回 JSON 报告。

## 项目工程化
AI 工程岗位非常看重工程化能力。学习重点包括模块化目录、配置管理、日志、异常处理、测试、依赖管理和 README。实践建议是让项目具备清晰入口、可复用服务、示例数据和可验证运行步骤。
